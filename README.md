# 🎴 UNO LAN — เล่นกับเพื่อนในวง Wi-Fi เดียวกัน

เกม UNO หลายคน (2–10 คน) แต่ละคนเปิดมือถือ/คอมของตัวเอง เห็นไพ่ในมือตัวเอง
เครื่องของคุณทำหน้าที่เป็น server ให้เพื่อนเชื่อมต่อเข้ามา

---

## วิธีติดตั้ง (ทำครั้งเดียว)

1. ติดตั้ง **Node.js** ก่อน (ถ้ายังไม่มี) — โหลดจาก https://nodejs.org เวอร์ชัน LTS
2. วางโฟลเดอร์นี้ไว้ที่ไหนก็ได้ เช่น `C:\Users\kc\Desktop\UNO`
3. เปิด Command Prompt / PowerShell แล้วเข้าไปในโฟลเดอร์:

   ```
   cd C:\Users\kc\Desktop\UNO
   ```

4. ติดตั้งไลบรารี:

   ```
   npm install
   ```

---

## วิธีเล่น

1. เริ่ม server:

   ```
   npm start
   ```

2. จะเห็นข้อความประมาณนี้:

   ```
   เครื่องนี้:      http://localhost:3000
   เครื่องอื่นในวง: http://192.168.x.x:3000
   ```

3. **เครื่องคุณเอง** เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
4. **เพื่อน** (ที่ต่อ Wi-Fi เดียวกัน) เปิด `http://192.168.x.x:3000` (เลข IP ตามที่ขึ้นจริง)
5. คนหนึ่งกด **สร้างห้องใหม่** → ได้รหัสห้อง 4 ตัว
6. คนอื่นพิมพ์รหัสนั้นแล้วกด **เข้าร่วมห้อง**
7. เจ้าของห้องกด **เริ่มเกม** (ต้องมีอย่างน้อย 2 คน)

---

## กฎที่รองรับ

- ลงไพ่ตามสี / เลข / สัญลักษณ์เดียวกัน
- ไพ่พิเศษ: ข้าม (Skip), ย้อนทิศ (Reverse), +2 (Draw 2)
- ไพ่ Wild: เปลี่ยนสี และ Wild +4
- ทบ +2 บน +2 และ +4 ได้ (stacking)
- กดจั่วเมื่อลงไม่ได้ — ถ้าจั่วแล้วลงได้ จะลงต่อหรือกด "ผ่าน" ก็ได้
- เหลือไพ่ใบเดียวจะขึ้นป้าย UNO อัตโนมัติ
- ใครหมดไพ่ก่อนชนะ

---

## ปัญหาที่พบบ่อย

- **เพื่อนเข้าไม่ได้** → ตรวจว่าต่อ Wi-Fi เดียวกัน และลองปิด Firewall ของ Windows ชั่วคราว
  (หรืออนุญาต Node.js ใน Windows Defender Firewall)
- **อยากเปลี่ยน port** → ตั้งค่า `set PORT=4000` ก่อน `npm start`
- **เกมค้าง** → เจ้าของห้องกดปุ่ม "เล่นใหม่ 🔄" เพื่อเริ่มรอบใหม่
